# Game de Motores 2D

Projeto da faculdade, de mar/2023 a jun/2023. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Projeto final da disciplina de motores 2D. É um jogo de plataforma com menu, 4 fases e uma cena final. Em alguns pontos o jogo pausa e mostra uma pergunta pra você digitar a resposta, e numa das partes as plataformas vão subindo até a altura do jogador enquanto a anterior cai. Também tem diálogos, inimigos patrulhando, teletransporte entre cenas e cronômetro.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.15f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

Usei o LeanTween nas animações e o TextMesh Pro. As artes estão em `Assets/Artes`.
